# Как загрузить эти файлы в GitHub

## Важно

Эти файлы нужно загрузить в корень репозитория проекта `ural-bani-chatlanding`.

Содержимое архива уже разложено по нужным папкам:
- `.npmrc` — в корень
- `vite.config.js` — в корень
- `AGENTS.md` — в корень
- `.github/workflows/ci.yml`
- `.github/workflows/deploy.yml`

## После загрузки

1. Откройте GitHub → вкладка Actions.
2. Дождитесь запуска CI и Deploy to GitHub Pages.
3. Если сборка красная, скопируйте текст ошибки и отправьте в ChatGPT.
